# 자료구조 개요

## 📌 1. 자료구조의 개념
자료구조는 **단순 구조, 선형 구조, 비선형 구조, 파일 구조**로 나뉜다. 본 강의에서는 먼저 **단순 구조**에 대한 데이터 표현 방식을 학습한다.

---
## 📂 2. 데이터 표현 방식
데이터 표현 방식은 **수치 자료, 문자 자료, 논리 자료, 포인터 자료, 문자열 자료**로 나뉜다.

### 🔢 2.1 수치 자료
- **10진수 표현**  
  - ✅ **존(Zone) 형식**: 인쇄용 문자 표현 방식  
  - ✅ **팩(Packed) 형식**: 숫자 표현 방식  
- **2진수 표현**  
  - ✅ **정수 표현**: 부호-절대값, 1의 보수, 2의 보수 방식  
  - ✅ **실수 표현**: 고정 소수점, 부동 소수점 방식  

#### 📌 2.1.1 고정소수점과 부동소수점 표현 방식

##### 1️⃣ 고정소수점 표현 방식
- 소수점의 위치가 **고정**되어 있음
- 정수 연산과 유사한 방식으로 계산
- 표현할 수 있는 **수의 범위가 제한적**

##### 2️⃣ 부동소수점 표현 방식
- **소수점이 고정되지 않음**
- 지수를 사용하여 **더 넓은 수의 범위를 표현** 가능
- 예: 213 → `0.213 × 10³`
- 부동소수점 표현 방식 구성 요소:
  - **부호 비트 (Sign Bit)**: 양수(0), 음수(1)
  - **지수부 (Exponent)**: 소수점 위치 결정
  - **가수부 (Mantissa)**: 유효 숫자를 저장
- **연산 시 반올림 오차 발생 가능**

### 📝 2.2 문자 자료
#### 1️⃣ BCD 코드 (Binary-Coded Decimal)
- **6비트 구조**
- **상위 2비트 (존 비트, Zone Bit)**: 문자 유형 구분
- **하위 4비트 (웨이트 비트, Weight Bit)**: 숫자 값을 표현
- 예: 'A' → `01 0001`

#### 2️⃣ EBCDIC 코드 (Extended Binary Coded Decimal Interchange Code)
- **IBM 계열 시스템**에서 사용되는 **8비트 문자 인코딩**
- **상위 4비트 (존 비트, Zone Bit)**: 문자 유형을 구분
- **하위 4비트 (숫자 비트, Digit Bit)**: 실제 문자 값 표현
- 예: 'A' → `11000001`

#### 3️⃣ ASCII 코드 (American Standard Code for Information Interchange)
- 현재 가장 **널리 사용되는 문자 인코딩 방식**
- **7비트 구조**:
  - **존 비트 (Zone Bit, 3비트)**: 문자 그룹 구분
  - **디짓 비트 (Digit Bit, 4비트)**: 실제 문자 값
- 예: 'A' → `1000001` (10진수 65)

### ✅ 2.3 논리 자료
논리 자료는 참(True)과 거짓(False)을 표현하는 자료형이다.  
주로 **1바이트의 최하위 비트**로 표현되며, 방식은 다음과 같다.
1. **최하위 비트가 1이면 참, 0이면 거짓**
2. **전체 비트가 1이면 참, 0이면 거짓**
3. **하나 이상의 비트가 1이면 참, 모두 0이면 거짓**  

### 📌 2.4 포인터 자료
- 메모리의 **주소를 표현하는 자료 형식**  
- 포인터는 **주소와 값**으로 구성됨  
- 하드디스크의 구조(트랙과 섹터)를 기반으로 저장 위치를 가짐  

### 🏷️ 2.5 문자열 자료
- 문자가 연속된 **집합**
- **저장 방식**  
  1. **구분자 방식**: 부분 문자열 사이에 구분자를 둬서 저장  
  2. **고정 길이 방식**: 일정한 길이로 저장 (메모리 낭비 발생 가능)  
  3. **포인터 방식**: 헤더를 두고 포인터를 이용해 문자열 위치 지정

## 🔍 3. 자료구조와 알고리즘
- **자료구조 = 데이터 + 연산 알고리즘**
- 예: 배열(데이터) + 순차 탐색(알고리즘) = 탐색 프로그램  

### 💡 3.1 알고리즘 개념
알고리즘은 **컴퓨터로 문제를 해결하기 위한 단계적 절차**이며, 다음 5가지 조건을 만족해야 한다.
1. **입력(Input)**: 0개 이상의 입력이 존재해야 함  
2. **출력(Output)**: 1개 이상의 출력이 반드시 존재해야 함  
3. **명확성(Definiteness)**: 명령이 명확해야 함  
4. **유한성(Finiteness)**: 반드시 종료해야 함  
5. **유효성(Effectiveness)**: 실행 가능한 연산이어야 함  

### ⚙️ 3.2 알고리즘 개발 과정
1. 문제 정의 → 요구사항 분석  
2. 알고리즘 작성 → 데이터 구조 지원  
3. 프로그램 작성 및 번역 (컴파일러/인터프리터)  
4. 실행 및 결과 확인

## 🎯 결론
고정소수점과 부동소수점 방식은 각각 장단점이 있으며, **응용 분야에 따라 적절한 방식이 선택**된다.  
또한 문자 인코딩 방식으로는 **BCD, EBCDIC, ASCII** 등이 있으며, **ASCII가 현재 가장 널리 사용**된다.  
이러한 표현 방식은 컴퓨터가 데이터를 처리하고 저장하는 데 **필수적인 개념**이다.
