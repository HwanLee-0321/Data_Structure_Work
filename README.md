# 📘 자료구조 강의 자료 (Data Structure Lecture Materials)

- 이 저장소는 **자료구조(Data Structure)** 강의의 주차별 학습 자료를 포함하고 있습니다. 각 주차별 이론 및 실습 내용을 정리한 Markdown 파일이 포함되어 있으며, 학습을 위한 가이드라인을 제공합니다.

## 📝 학습 내용
### 📌 1주차 (Week 1)
- 자료구조 개요 및 기본 개념
- 데이터 표현 방식
- 배열과 리스트

### 📌 2주차 (Week 2)
- 스택(Stack)과 큐(Queue)
- 연결 리스트(Linked List)
- 실습 문제 및 코드 구현

## 🔧 활용 방법
1. `weekX_theory.md` 파일을 통해 이론 내용을 학습합니다.
2. `weekX_practice.md` 파일의 실습 문제를 풀어보며 개념을 응용합니다.
3. 추가적인 코드 구현을 진행하여 자료구조 개념을 심화 학습합니다.
