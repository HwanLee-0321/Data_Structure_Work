## 1. 셸 정렬 (Shell Sort) 🐚

셸 정렬은 **삽입 정렬의 단점(요소들의 이동이 인접한 위치로만 제한된다는 점)**을 보완하기 위해 고안된 정렬 알고리즘입니다. **불연속적인 부분 리스트를 정렬**하여 원거리에 있는 요소들도 빠르게 이동시킬 수 있다는 장점이 있습니다.

### 핵심 개념

* **갭 (Gap) 또는 간격:** 전체 리스트를 일정한 간격으로 나누어 여러 개의 부분 리스트(불연속적)를 만드는 데 사용되는 값입니다.
* **삽입 정렬 활용:** 셸 정렬은 이 불연속적인 부분 리스트에 대해 **삽입 정렬**을 적용합니다.
* **점진적인 간격 감소:** 갭은 점차적으로 줄어들어 마지막에는 1이 됩니다. 갭이 1이 되면 사실상 일반적인 삽입 정렬과 동일하게 동작하며, 이전에 부분적으로 정렬된 상태 덕분에 삽입 정렬의 효율이 극대화됩니다.

### 동작 방식

1.  **초기 갭 설정:** 적절한 초기 갭 값(예: $N/2$, $N/2 + 1$, 또는 특정 수열)을 설정합니다.
2.  **부분 리스트 정렬:** 설정된 갭을 기준으로 리스트를 여러 개의 불연속적인 부분 리스트로 나눕니다. 각 부분 리스트 내에서 삽입 정렬을 수행합니다.
    * **예시:** 갭이 5일 때, `list[0], list[5], list[10], ...` 이 하나의 부분 리스트가 되고, `list[1], list[6], list[11], ...` 이 또 다른 부분 리스트가 됩니다.
3.  **갭 감소:** 갭을 일정한 비율로 줄입니다 (예: `gap = gap / 2`).
4.  **반복:** 갭이 1이 될 때까지 2~3단계를 반복합니다.
5.  **최종 정렬:** 갭이 1이 되면 전체 리스트에 대해 삽입 정렬을 수행하여 최종적으로 정렬을 완료합니다.

### 셸 정렬 예시 (초기 갭: 5, 다음 갭: 2(교재는 3), 최종 갭: 1)

* **초기 리스트:** `[10, 3, 8, 22, 6, 1, 20, 0, 4, 15, 16]` (총 11개 요소)

1.  **1차 정렬 (Gap = 5):**
    * `[10, 1]` 비교 & 교환 → `[1, 3, 8, 22, 6, 10, 20, 0, 4, 15, 16]`
    * `[3, 0]` 비교 & 교환 → `[1, 0, 8, 22, 6, 10, 20, 3, 4, 15, 16]`
    * `[8, 4]` 비교 & 교환 → `[1, 0, 4, 22, 6, 10, 20, 3, 8, 15, 16]`
    * `[22, 15]` 비교 & 유지
    * `[6, 16]` 비교 & 유지
    * **1차 정렬 결과:** `[1, 0, 4, 15, 6, 10, 20, 3, 8, 22, 16]` (예시와 다소 차이 있을 수 있음. 부분 리스트 내 삽입 정렬이므로 실제 과정은 더 복잡)
        * [Image of Shell Sort gap 5 example]

2.  **2차 정렬 (Gap = 2 또는 3):**
    * 강의에서는 갭을 2로 나누지만, 교재는 인위적으로 3으로 설정했다고 언급했습니다. (교수님은 2로 구현하는 실습을 지시)
    * **Gap = 2일 경우:** `list[0], list[2], list[4], ...`, `list[1], list[3], list[5], ...` 와 같은 부분 리스트들을 정렬합니다.
    * **2차 정렬 결과:** 1차 정렬 결과보다 더욱 정렬된 상태가 됩니다.
        * [Image of Shell Sort gap 2 example]

3.  **3차 정렬 (Gap = 1):**
    * 갭이 1이 되면 전체 리스트에 대해 삽입 정렬을 수행합니다. 이때 리스트는 이미 어느 정도 정렬되어 있으므로 삽입 정렬이 매우 빠르게 완료됩니다.
    * **최종 정렬 결과:** `[0, 1, 3, 4, 6, 8, 10, 15, 16, 20, 22]`
        * [Image of Shell Sort gap 1 example]

### 특징

* **장점:**
    * 삽입 정렬의 단점인 **원거리 자료 이동의 제한**을 극복합니다. 요소들이 멀리 떨어져 있어도 효율적으로 이동할 수 있습니다.
    * 부분 리스트가 점진적으로 정렬된 상태가 되므로, 최종 단계의 삽입 정렬 속도가 매우 빨라집니다.
* **시간 복잡도:**
    * **평균:** $O(N^{1.5})$
    * **최악:** $O(N^2)$
* **안정성:** **불안정** (동일한 키 값의 상대적 위치가 바뀔 수 있음)
* 셸 정렬 함수 내부에 삽입 정렬 함수가 포함되어 구현됩니다.

## 2. 병합 정렬 (Merge Sort) 🌳

병합 정렬은 **'분할 정복 (Divide and Conquer)'** 기법을 사용하는 대표적인 정렬 알고리즘입니다. 큰 문제를 작은 문제로 나누어 해결하고, 그 결과를 합치는 방식입니다.

### 핵심 개념

* **분할 정복 (Divide and Conquer):**
    1.  **분할 (Divide):** 정렬할 리스트를 두 개(또는 그 이상)의 부분 리스트로 나눕니다.
    2.  **정복 (Conquer):** 각 부분 리스트를 재귀적으로 정렬합니다. 부분 리스트의 크기가 충분히 작아지면 (예: 요소가 하나만 남으면) 정렬이 완료된 것으로 간주합니다.
    3.  **결합 (Combine) 또는 병합 (Merge):** 정렬된 부분 리스트들을 합쳐(병합하여) 하나의 정렬된 리스트를 만듭니다. 실제로 정렬이 이루어지는 시점은 이 병합 단계입니다.

### 동작 방식

1.  **분할:** 리스트를 더 이상 나눌 수 없을 때(요소가 1개가 될 때)까지 절반으로 계속 나눕니다.
2.  **정복 (재귀적 호출):** 분할된 각 부분 리스트를 정렬합니다. 요소가 1개인 리스트는 이미 정렬된 것으로 봅니다.
3.  **병합:** 정렬된 두 개의 부분 리스트를 합쳐 하나의 정렬된 리스트로 만듭니다. 이때, 각 리스트의 첫 번째 요소부터 비교하여 작은 값을 새 리스트에 넣는 방식으로 진행합니다.

### 병합 정렬 예시

* **초기 리스트:** `[26, 5, 37, 1, 61, 11, 59, 15]` (총 8개 요소)

1.  **분할 단계:**
    * `[26, 5, 37, 1]`, `[61, 11, 59, 15]`
    * `[26, 5]`, `[37, 1]`, `[61, 11]`, `[59, 15]`
    * `[26]`, `[5]`, `[37]`, `[1]`, `[61]`, `[11]`, `[59]`, `[15]` (더 이상 분할 불가)
    * [Image of Merge Sort divide phase]

2.  **병합 단계:**
    * `[5, 26]`, `[1, 37]`, `[11, 61]`, `[15, 59]` (정렬 후 병합)
    * `[1, 5, 26, 37]`, `[11, 15, 59, 61]` (정렬 후 병합)
    * `[1, 5, 11, 15, 26, 37, 59, 61]` (최종 병합)
    * [Image of Merge Sort merge phase]

### 특징

* **시간 복잡도:**
    * **최선, 평균, 최악:** $O(N \log N)$ (균등 분할로 $\log N$번의 패스가 발생하고, 각 패스에서 $N$번의 비교 연산이 이루어집니다.)
* **안정성:** **안정적** (동일한 키 값의 상대적 위치가 유지됨)
* **메모리 사용:** 추가적인 임시 배열 공간이 필요하므로 메모리 사용량이 많습니다. (레코드 크기가 큰 경우 시간적 낭비 초래 가능)
* 연결 리스트로 구성하여 병합 정렬을 할 경우 매우 효율적입니다.

## 3. 퀵 정렬 (Quick Sort) 🚀

퀵 정렬은 **'평균적으로 가장 빠른 정렬 방법'**으로 알려져 있으며, 병합 정렬과 마찬가지로 **분할 정복 기법**을 사용합니다.

### 핵심 개념

* **피벗 (Pivot):** 리스트를 두 개의 부분 리스트로 분할하기 위한 **기준 값**입니다. 피벗을 기준으로 리스트를 나눕니다.
* **비균등 분할:** 피벗 값에 따라 부분 리스트의 크기가 달라질 수 있습니다. 피벗의 위치에 따라 효율성이 크게 달라집니다.
* **재귀 호출:** 각 부분 리스트에 대해 재귀적으로 퀵 정렬을 호출하여 정렬을 완료합니다.

### 동작 방식

1.  **피벗 선택:** 리스트 내에서 하나의 요소를 피벗으로 선택합니다. (강의에서는 '가장 왼쪽에 있는 숫자'를 피벗으로 설정)
2.  **분할 (Partition):**
    * 피벗을 기준으로 리스트를 두 개의 부분 리스트로 나눕니다.
    * 피벗보다 **작은 값들은 피벗의 왼쪽**에, 피벗보다 **큰 값들은 피벗의 오른쪽**에 위치시킵니다.
    * `low` 포인터는 피벗보다 작은 값을 찾기 위해 오른쪽으로 이동하고, `high` 포인터는 피벗보다 큰 값을 찾기 위해 왼쪽으로 이동합니다.
    * `low`와 `high`가 교차하면 분할이 완료됩니다.
3.  **정복 (재귀적 호출):** 분할된 왼쪽 부분 리스트와 오른쪽 부분 리스트에 대해 재귀적으로 퀵 정렬을 호출합니다.

### 퀵 정렬 예시

* **초기 리스트:** `[5, 3, 7, 8, 2, 6, 9, 4, 1]`
* **피벗 선택:** `5` (가장 왼쪽 요소)

1.  **1차 분할 (피벗 = 5):**
    * `low`와 `high` 포인터가 움직이며 5보다 작은 2, 4, 1은 왼쪽으로, 5보다 큰 7, 8, 6, 9는 오른쪽으로 이동합니다.
    * 결과: `[1, 2, 3, 4, 5, 9, 6, 8, 7]` (피벗 5는 제자리를 찾음)
    * [Image of Quick Sort partition 1]

2.  **재귀적 분할 (좌측 리스트: `[1, 2, 3, 4]`, 피벗 = 1):**
    * `[1]`을 기준으로 `[2, 3, 4]`가 정렬됩니다.
    * [Image of Quick Sort partition 2]

3.  **재귀적 분할 (우측 리스트: `[9, 6, 8, 7]`, 피벗 = 9):**
    * `[9]`를 기준으로 `[6, 8, 7]`이 정렬됩니다.
    * [Image of Quick Sort partition 3]

이 과정을 부분 리스트의 크기가 1이 될 때까지 반복하여 최종적으로 정렬된 리스트를 얻습니다.

### 특징

* **시간 복잡도:**
    * **평균:** $O(N \log N)$ (매우 효율적)
    * **최악:** $O(N^2)$ (피벗 선택이 매우 비효율적일 때 발생, 예: 이미 정렬된 리스트에서 항상 첫 번째 요소를 피벗으로 선택하는 경우)
* **안정성:** **불안정** (동일한 키 값의 상대적 위치가 바뀔 수 있음)
* 별도의 임시 배열이 필요하지 않아 메모리 효율적입니다.

## 👨‍🏫 교수님께서 중요하다고, 시험에 나온다고 한 부분 📝

교수님의 강의 스크립트를 분석한 결과, 다음 내용들이 시험 출제 가능성이 높거나, 학습 시 반드시 이해해야 할 핵심 개념으로 강조되었습니다.

* **데이터 계층 구조:**
    * **필드(아이템) -> 레코드**의 관계 이해.
    * **문자 표현 방법:** **아스키 코드와 EBCDIC 코드** (중간고사에 냈던 내용이라고 강조).
* **정렬 알고리즘 평가 기준:**
    * **비교 횟수**와 **이동 횟수**가 정렬 알고리즘의 효율성을 평가하는 중요한 기준임을 이해.
* **정렬 알고리즘의 안정성 (Stability) 개념:**
    * "동일한 키 값을 받은 레코드들의 **상대적 위치가 정렬 후에도 바뀌지 않는 것**"이라는 정의를 명확히 이해해야 합니다.
    * **안정적인 정렬** (삽입 정렬, 버블 정렬)과 **불안정한 정렬** (선택 정렬, 퀵 정렬)을 구분할 수 있어야 합니다. (공과금 예시를 통해 안정성 중요성을 강조)
* **각 정렬 알고리즘의 핵심 특징 및 시간 복잡도:**
    * **단순하지만 비효율적인 정렬 ($O(N^2)$)**:
        * **선택 정렬:** 구현 원리(최솟값 찾아 교환), **$O(N^2)$ 시간 복잡도 (비교/이동 횟수 과다로 비효율적)**, **불안정성**.
        * **삽입 정렬:** 구현 원리(정렬된 곳에 삽입), **안정적**, **이미 정렬된 경우 $O(N)$으로 효율적**, 최악의 경우 **$O(N^2)$**. (레코드 이동이 많아 레코드 크기 크면 불리)
        * **버블 정렬:** 구현 원리(인접한 두 개 교환), **$O(N^2)$ 시간 복잡도 (최상/평균/최악 모두 동일)**, **레코드 이동 과다**, **안정적**.
    * **복잡하지만 효율적인 정렬 ($O(N \log N)$)**:
        * **셸 정렬:** 삽입 정렬의 단점 보완 (원거리 이동 가능), **$O(N^{1.5})$ 평균 시간 복잡도**, **불안정성**. (간격(갭)의 중요성 강조)
        * **병합 정렬:** **분할 정복 기법의 대표 예시**, **$O(N \log N)$ 시간 복잡도 (항상 일정)**, **안정적**. (병합 단계에서 실제 정렬이 이루어짐, 추가 메모리 필요)
        * **퀵 정렬:** **평균적으로 가장 빠른 정렬 ($O(N \log N)$)**, **분할 정복 기법**, **피벗의 중요성 (비균등 분할 가능)**, **불안정성**, 최악의 경우 **$O(N^2)$**.
* **프로그래밍 실습의 중요성:**
    * **각 정렬 알고리즘의 C/C++ 구현** (교재의 함수를 사용하되, `main` 함수를 수정하여 **단계별 정렬 과정과 출력 결과**를 명확히 보여줄 것).
    * 특히 셸 정렬 실습 시 **갭(간격) 설정** (교재와 달리 2로 설정)에 유의할 것을 강조.
    * **제출 기한**과 **결과 확인**을 여러 번 언급하며 실습의 중요성을 강조했습니다.
