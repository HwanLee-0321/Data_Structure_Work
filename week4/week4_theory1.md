
# 컴파일러와 표현 방식에 대한 강의 요약

## 1. 표현 방식의 종류

### 중위 표현 (Infix Notation)
- 일반적으로 사람이 사용하는 방식
- 예: `2 + 3 * 4`
- 우선순위에 따라 계산 순서 결정: **승·제·가·감**

### 전위 표현 (Prefix Notation)
- 연산자가 앞에 위치
- 예: `+ 2 * 3 4`

### 후위 표현 (Postfix Notation)
- 연산자가 뒤에 위치
- 예: `2 3 4 * +`

---

## 2. 연산자의 분류와 우선순위

- **산술 연산자**: `+`, `-`, `*`, `/`
- **관계 연산자**: `>`, `<`, `==`, `!=`
- **논리 연산자**: `&&`, `||`
- 우선순위: 산술 > 관계 > 논리
- 같은 우선순위에서는 **좌 → 우 연산**

---

## 3. 표현식 변환

### 예시 1: `A * B + 1`
- 중위 표현: `A * B + 1`
- 전위 표현: `+ * A B 1`
- 후위 표현: `A B * 1 +`

### 괄호 사용 예: `(1 + 2) + 7`
- 전위 표현: `+ + 1 2 7`
- 후위 표현: `1 2 + 7 +`

---

## 4. 후위 표기식 계산 알고리즘

1. 수식을 **왼쪽 → 오른쪽** 스캔
2. **피연산자**이면 **스택에 저장**
3. **연산자**이면 필요한 수만큼 피연산자를 꺼내 연산
4. 연산 결과를 다시 스택에 저장

### 예시 계산: `8 2 / 3 - 3 2 * +`
- `8 2 /` → `4`
- `4 3 -` → `1`
- `3 2 *` → `6`
- `1 + 6` → `7`

---

## 5. 중위 → 후위 변환 알고리즘 요약

- **피연산자**: 즉시 출력
- **연산자**: 스택에 저장
- **우선순위 낮은 연산자**: 스택의 연산자를 출력
- **괄호**:
  - `(`: 가장 낮은 우선순위로 스택에 저장
  - `)`: `(` 위의 모든 연산자를 출력

---

## 6. 미로 탐색 문제 (스택 응용)

### 미로 표현
- 2차원 배열로 표현 (0: 통로, 1: 벽, 2: 시작, x: 출구)

### 탐색 로직
1. 현재 위치에서 **이동 가능한 방향**을 스택에 저장
2. 막히면 스택에서 꺼내 **백트래킹**
3. 방향 우선순위: **위 → 아래 → 좌 → 우**

### 포인터 이동 기준
- 위: `row - 1`
- 아래: `row + 1`
- 좌: `col - 1`
- 우: `col + 1`

---

## 7. 요약

- 컴파일러는 중위 표현을 **후위 표현으로 변환**하여 계산
- 변환 및 계산 과정은 **스택**을 활용
- 미로 탐색 등 다양한 알고리즘에도 **스택 구조 활용**
