# 🌳 트리(Tree) 기본 개념 정리

## 📌 1. 루트 노드(Root Node)
- **정의**: 부모가 없는 노드
- **예시**:
  ```
       A
      / \
     B   C
  ```
  - A: 루트 노드 (부모 없음)

---

## 📌 2. 서브트리(Subtree)
- **정의**: 하나의 자식 노드를 루트로 하는 하위 트리 구조
- **예시**:
  ```
       A
      / \
     B   C
    /
   D
  ```
  - B의 서브트리: B-D
  - A의 서브트리: 전체 트리에서 A 제외한 각각의 하위 구조

---

## 📌 3. 단말 노드(Leaf Node) & 비단말 노드(Internal Node)
- **단말 노드**: 자식이 없는 노드
- **비단말 노드**: 하나 이상의 자식을 가진 노드
- **예시**:
  ```
       A
      / \
     B   C
    /
   D
  ```
  - 단말 노드: C, D
  - 비단말 노드: A, B

---

## 📌 4. 노드 관계 용어
- **부모 노드 (Parent)**: 자식 노드를 가지는 노드
- **자식 노드 (Child)**: 부모 노드로부터 내려온 노드
- **형제 노드 (Sibling)**: 같은 부모를 가지는 노드
- **조상 노드 (Ancestor)**: 루트에서 자신까지 경로에 있는 모든 상위 노드
- **자손 노드 (Descendant)**: 현재 노드에서 아래로 이어지는 모든 노드
- **예시**:
  ```
       A
      / \
     B   C
    / \
   D   E
  ```
  - B의 부모: A
  - B의 자식: D, E
  - D와 E는 형제
  - A는 D의 조상, D는 A의 자손

---

## 📌 5. 레벨(Level) & 높이(Height)
- **레벨(Level)**: 루트 기준으로 몇 층인지 표시 (루트는 1레벨 또는 0레벨)
- **높이(Height)**: 트리의 최대 레벨
- **예시**:
  ```
       A (레벨 1)
      / \
     B   C (레벨 2)
    /
   D (레벨 3)
  ```
  - 높이: 3

---

## 📌 6. 차수(Degree)
- **정의**: 한 노드가 가지는 자식 노드 수
- **트리의 차수**: 전체 노드들 중 최대 차수를 가진 노드의 차수
- **예시**:
  ```
       A
      /|\
     B C D
  ```
  - A의 차수: 3
  - 트리의 차수: 3

---

## 📌 7. 이진 트리(Binary Tree)
- **정의**: 모든 노드가 최대 두 개의 자식을 갖는 트리
- **특징**:
  - 왼쪽 자식, 오른쪽 자식으로 구분됨
  - 서브트리는 공집합(null) 가능

### ✅ 주요 분류:
| 유형 | 설명 | 예시 |
|------|------|------|
| 포화 이진 트리 | 모든 노드가 자식 0개 또는 2개 | 완전한 피라미드 형태 |
| 완전 이진 트리 | 마지막 레벨을 제외하고 왼쪽부터 채워짐 | 힙 구조에 사용 |
| 편향 이진 트리 | 한쪽으로만 자식 존재 | 왼쪽/오른쪽만 이어짐 |

#### 예시
- 포화 이진 트리:
  ```
       A
      / \
     B   C
    / \ / \
   D  E F  G
  ```

- 완전 이진 트리:
  ```
       A
      / \
     B   C
    / \  
   D   E
  ```

- 왼쪽 편향:
  ```
   A
  /
 B
/
C
  ```

---

## 📌 8. 이진 트리 구현 방법

### 1. 배열(Array) 기반 구현
- 포화 이진 트리를 기준으로 번호를 붙이고, 인덱스에 맞춰 저장
- **예시**:
  - 루트를 1번으로 두고 왼쪽 자식은 2i, 오른쪽 자식은 2i+1

### 2. 포인터(Pointer) 기반 구현
- 각 노드가 왼쪽/오른쪽 자식 노드를 가리키는 포인터를 가짐
- 동적 구조 구현에 적합

---

## 📌 9. 이진 트리 특성 정리
- 노드 수: n
- 간선 수: n - 1
- 높이 h인 이진 트리의 최대 노드 수: 2^h - 1
- 높이 h인 이진 트리의 최소 노드 수: h (편향 트리)
