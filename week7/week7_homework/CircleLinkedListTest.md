# 🌀 CircleLinkedListTest.c

> **Circular Linked List**(원형 연결 리스트)의 동작을 테스트하는 C 언어 기반의 샘플 코드입니다.

---

## 📌 개요

이 파일은 **원형 연결 리스트(Circular Linked List)**의 핵심 동작을 점검하는 테스트 프로그램입니다. 연결 리스트의 삽입, 삭제, 순회 등 다양한 연산을 시뮬레이션하여 해당 구조가 올바르게 동작하는지 검증합니다.

---

## 📚 주요 기능

### 🔹 노드 삽입
- 리스트의 **앞쪽, 중간, 뒤쪽**에 노드를 삽입하는 기능
- 삽입 시 원형 구조를 유지하도록 링크 조정

### 🔹 노드 삭제
- 특정 노드를 제거하고 포인터를 재연결
- **빈 리스트에 대한 예외 처리** 포함

### 🔹 리스트 순회 및 출력
- **헤드 노드부터 시작**하여 모든 노드 정보를 출력
- **원형 순환 구조** 특성상, **출발 지점 도달 시 종료**

### 🔹 기타 유틸리티
- 리스트 초기화  
- 노드 개수 계산  
- 특정 노드 검색
