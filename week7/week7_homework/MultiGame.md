# 🎮 MultiGame.c

> 플레이어 이름을 원형 연결 리스트(Circular Linked List)에 저장하고 반복 순회하며 출력하는 간단한 게임용 C 프로그램입니다.

---

## 📌 개요

- 이름 데이터를 담은 노드를 원형 연결 리스트 형태로 구성
- `insert_first()` 함수를 통해 노드를 리스트에 추가
- `main()` 함수에서 리스트를 순회하며 플레이어 이름을 출력

---

## 📚 주요 기능

### 🔹 노드 삽입

```c
ListNode *insert_first(ListNode *head, element data);
```
- 리스트가 비어있다면 자기 자신을 가리키도록 초기화
- 아니라면 `head->link` 다음에 새로운 노드를 삽입  
- 삽입된 노드는 항상 `head`의 바로 다음에 위치

---

### 🔹 순환 출력

```c
for (int i = 0; i < 10; i++) {
    printf("현재 순번 = %s\n", p->data);
    p = p->link;
}
```
- 원형 리스트이므로 10번 이상 순회해도 무한히 돌 수 있음
- 리스트 내 노드 개수보다 큰 반복 횟수를 설정해도 문제 없이 동작

---

## 🧠 구조체 정의

```c
typedef char element[100];

typedef struct {
    element data;
    struct ListNode *link;
} ListNode;
```

- `element`: 문자열 이름 저장용
- `link`: 다음 노드를 가리키며, 마지막 노드는 처음 노드를 다시 가리킴
